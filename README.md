# disk-scheduling_simulator
A Python-based Disk Scheduling Algorithm Simulator that implements FCFS, SSTF, SCAN, C-SCAN, LOOK, and C-LOOK algorithms. It calculates disk head movement and uses Matplotlib graphs to visualize and compare algorithm performance for better understanding of Operating Systems concepts.
